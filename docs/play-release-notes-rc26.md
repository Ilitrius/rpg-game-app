# Play Console: "Was ist neu" für 0.1.0-rc26

Format für die Play Console (Release-Notizen je Sprache, max. 500 Zeichen). Einfügen unter Test → Closed Test → Release erstellen.

• Tutorial erweitert (9 Schritte)
