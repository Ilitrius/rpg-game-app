Idle RPG – Datenschutzerklärung

Stand: 25.10.2026

Kurzfassung: Die App „Idle RPG“ (com.rp.IDLEGAMERP) erhebt, speichert auf Servern oder teilt keinerlei personenbezogene Daten.

Verantwortlicher / Kontakt

Ilitrius (René P.), E-Mail: rene.puf@gmail.com

Welche Daten werden verarbeitet?

  • Spielstand und Einstellungen (Charakter, Ausrüstung, Gold, Sprache, Ton) werden ausschließlich lokal auf deinem Gerät gespeichert.
  • Die App benötigt keine Berechtigungen, hat keine Konten, keine Werbung und keine Analyse- oder Tracking-Dienste. Sie baut selbst keine Internetverbindungen auf. Einzige Drittanbieter-Komponente ist die Google-Play-Bibliothek „In-App Updates“ (siehe nächster Punkt).
  • Update-Hinweis: Um dich auf neue Versionen hinzuweisen, fragt die App über die Google-Play-Bibliothek „In-App Updates“ beim Google-Play-Store an, ob für diese App ein Update verfügbar ist. Die Abfrage läuft über die Play-Dienste auf deinem Gerät; die App selbst sendet dabei keine Spiel- oder personenbezogenen Daten und erhält nur den Update-Status. Welche Daten Google dabei verarbeitet, regelt die Datenschutzerklärung von Google. Ohne Google Play (z. B. Installation per Datei) passiert nichts.
  • Es gibt keine Cloud-Sicherung (Android-Backup ist deaktiviert).
  • Freiwillige Spende: Der Button „Spenden“ in den Optionen öffnet in deinem Browser eine externe Zahlungsseite von Stripe. Die App übergibt dabei keine Daten und schaltet durch eine Spende nichts frei. Die Zahlung wird ausschließlich von Stripe abgewickelt; dabei erhebt Stripe die für die Zahlung nötigen Angaben (z. B. Zahlungsdaten, E-Mail-Adresse), und der Entwickler erhält davon die Angaben, die Stripe bereitstellt (z. B. Name, E-Mail, Betrag). Es gilt die Datenschutzerklärung von Stripe (stripe.com/privacy). Die Nutzung ist freiwillig.
  • Export/Import des Spielstands erfolgt manuell über Datei oder Zwischenablage; die Daten verlassen das Gerät nur, wenn du sie selbst weitergibst.
  • Diese Erklärung wird über GitHub Pages bereitgestellt. Beim Aufruf dieser Webseite verarbeitet GitHub technisch bedingt Verbindungsdaten (z. B. IP-Adresse); darauf hat der Entwickler keinen Einfluss. Die App selbst stellt keine Verbindung her.

Weitergabe an Dritte

Es findet keine Weitergabe statt.

Löschung

Alle Daten werden durch Deinstallation der App gelöscht. Eine Zurücksetzen-Funktion gibt es nicht; ein Import überschreibt den bisherigen Spielstand.

Kinder

Die App richtet sich nicht gezielt an Kinder unter 13 Jahren und erhebt keine Daten von ihnen.

Idle RPG – Privacy Policy

Last updated: 25 October 2026

Summary: “Idle RPG” (com.rp.IDLEGAMERP) does not collect, transmit to any server, or share any personal data.

Contact

Ilitrius (René P.), email: rene.puf@gmail.com

Data processed

  • Save game and settings (character, equipment, gold, language, sound) are stored only locally on your device.
  • The app requests no permissions and has no accounts, ads, analytics or tracking. It does not open internet connections itself. The only third-party component is Google’s Play library “In-App Updates” (see next item).
  • Update notice: to tell you about new versions, the app asks the Google Play Store, via Google’s “In-App Updates” library, whether an update for this app is available. The query runs through Play services on your device; the app itself sends no game or personal data and only receives the update status. Google’s privacy policy governs what Google processes. Without Google Play (e.g. sideloaded install) nothing happens.
  • There is no cloud backup (Android backup is disabled).
  • Voluntary donation: the “Donate” button in Options opens an external Stripe payment page in your browser. The app passes no data and a donation unlocks nothing in the game. The payment is handled solely by Stripe; Stripe collects the details needed for the payment (e.g. payment data, email address), and the developer receives the details Stripe provides (e.g. name, email, amount). Stripe’s privacy policy applies (stripe.com/privacy). Using it is optional.
  • Save export/import is manual via file or clipboard; data leaves your device only if you share it yourself.
  • This policy is served via GitHub Pages. When you open this web page, GitHub technically processes connection data (e.g. IP address), which the developer cannot influence. The app itself makes no connection.

Sharing

No data is shared with third parties.

Deletion

Uninstalling the app deletes all data. The game has no reset function; an import overwrites the current save game.

Children

The app is not directed at children under 13 and collects no data from them.
