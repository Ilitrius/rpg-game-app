# Agenten-Lernspeicher

Agenten haben zwischen Aufträgen kein Gedächtnis — dieses Verzeichnis ist es.

- `shared.md` — Erkenntnisse, die für **alle** Agenten gelten (voneinander lernen).
- `<agent>.md` — eigene Erkenntnisse je Agent (`charakter`, `ausruestung`, `shop`, `optionen`, `spielwelt`).

## Regeln für Einträge
- Format: `- [YYYY-MM-DD] <Erkenntnis> — **Warum:** <Grund/Anlass>` (kurz, konkret, umsetzbar).
- Nur Nicht-Offensichtliches: Fallen, Entscheidungen, was funktioniert/nicht funktioniert hat, Qualitäts-Lektionen. Nichts, was im Code oder CLAUDE.md steht.
- Betrifft es andere Agenten → `shared.md`. Betrifft es nur dich → eigene Datei.
- Veraltete/falsche Einträge korrigieren oder löschen statt widersprechende anhängen.
- Eigene Datei max. ~40 Einträge; wenn voller: zusammenfassen.
- Fremde Agenten-Dateien nur lesen, nie schreiben.

Der Haupt-Thread kuratiert regelmäßig (Duplikate zusammenführen, Bewährtes in Agenten-Definitionen oder CLAUDE.md übernehmen).
